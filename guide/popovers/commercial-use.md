### 상업적 사용 제한 — 문서 기준 요약

| 구분 | 정리 |
|---|---|
| 내용적 판단근거 | 자동 감지 여부: 약관문서에 없음 |
| 감지·점검의 계기와 절차(자동, 신고, 수동) | 약관문서에 없음 |
| 물리적 판단근거 | 사용 한도가 기준(한도 초과로 인한 중지에만 해당, 문서에 있음) |
| 의미적 판단근거 | 이익을 얻는 목적인가의 사실관계(문서의 정의에 있음). 평소에는 사용자가 판단 |
| 정책 위반 시 처리 | 일시 중지와 이메일 안내(문서에 있음) |
| Hobby 지원 | 이메일 지원 없음(문서에 있음) |
