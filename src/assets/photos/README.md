# 실제 사진 넣는 곳

`<유형>/<모티프>.jpg|webp|png` 형식으로 넣으면 같은 모티프의 일러스트(`../art`)를 자동으로 대체한다.

- 유형: minimal · full · mid-a · mid-b
- 모티프: hero · building · location · park · plan · interior · community · video
- 현재 들어 있는 사진은 데모용 Pexels 무료 사진이며 출처는 `CREDITS.md`에 있다. 현장에서는 모두 현장 사진으로 교체/삭제한다.
- 라이선스가 확인된 이미지만 넣는다(촬영권/구매/무료 라이선스). 다른 사이트의 이미지를 그대로 가져오지 않는다.
- 권장: hero 1920×960 이상, 나머지 1200×750 이상(가로형), WebP/JPEG 200~400KB.
