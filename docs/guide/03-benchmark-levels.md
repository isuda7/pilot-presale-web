# 3. 벤치마킹 후보 → 4레벨 → 설계 활용

> 상세 근거: `docs/benchmark.md` (매트릭스, 사이트별 구조)

## 1. 후보와 한계
- 후보 10곳: 청주 씨엘리체, 써밋 더힐, 장위 마크원, 거제 마린피스, 써밋 클라비온, 검암역 프라베뉴, 두정역 그랑피크, 청라 아크원, 괴정역 더 센트럴, 경북도청 퍼스티온.
- **한계**: 전부 푸르지오·써밋 계열이다. 분양 사이트 전체의 평균이 아니다. 신청 폼 입력 항목은 미확인. 메뉴는 메인 페이지에서만 읽었다.
- 다른 브랜드가 필요하면 현장 주소를 받아 같은 방식으로 추가한다(아래 5절).

## 2. 4개 레벨 판정 기준
| 레벨 | 의미 | 판정 기준 | 이 프로젝트에서의 처리 |
|---|---|---|---|
| L1 필수 공통 | 모든 현장에 항상 있음 | 후보 전부(또는 서비스 필수) | 기본에 구현, 끌 수 없음 |
| L2 선택 공통 | 있으면 쓰고 없으면 끔 | 절반 이상 | 기본에 구현, `modules`로 켜고 끔 |
| L3 예외 유형 | 일부 유형에만 필요한 구조 | 소수 (1~2곳) | 유형이 `addModules`/파일 교체로 추가 |
| L4 현장 고유 데이터 | 값만 다름 | 현장명, 전화, 문구, 일정, 목록 | `config/site.ts` / `content` |

- **L3와 L4의 경계**: 구조가 다르면 L3, 값만 다르면 L4. (평면 타입이 3개든 8개든 L4, 오피스텔 분리 메뉴는 L3)
- **승격**: 같은 L3가 2곳 이상 반복되면 L2로 올린다. 이미 후보 분석에서 청약안내(8, 10), 지역조감VR(7, 8), 방문예약(2, 5)이 승격됐다.
- 3~4곳에서만 보이는 항목(인지세·자금조달·명의변경·마감재 등)은 메뉴가 아니라 **페이지 안의 목록**이므로 L4(값)로 처리한다.

## 3. 결과 요약
- **L1**: 사업개요, 입지환경, 프리미엄, 오시는길, 언론보도, 신청 폼, 개인정보처리방침
- **L2**: 분양일정, 공급안내, 모집공고, 청약안내, 계약안내, 단지설계, 커뮤니티, 배치도, 이동통신설비, 지역조감VR, 평면안내, E-모델하우스, 인테리어, 시스템, 홍보영상, 이벤트
- **L3**: 토지등소유자 계약안내(5번만), 오피스텔·근린생활시설 분리(8번만)
- **구조 유형**: A 표준형(1,3,4,6,7 + 2,5는 설정 차이), B 간결형(9,10), C 복합·청약형(8)

## 4. 설계에 활용하는 순서
새 현장 요구를 받았을 때 이 순서로 판단한다.
1. **L1 확인**: 필수 항목이 빠지지 않았는가
2. **템플릿 유형 선택**: 요구에 가장 가까운 것을 고른다 — 최소형(L1만) / 풀옵션형(L1+L2 전부+L3) / 중간형 A(분양·계약 정보 중심) / 중간형 B(상품·입지 비주얼 중심). 헤더·히어로·서브 이동 같은 레이아웃은 변형 중에서 고른다.
3. **L2 켜고 끄기**: 기획 자료에 있는 메뉴만 켠다
4. **L3 판단**: 기획 자료에 기존 유형에 없는 구조가 있는가. 있으면 `addModules` + 페이지 추가. 이미 다른 현장에서 요구한 적이 있으면 L2 승격을 제안한다
5. **L4 입력**: 현장명·전화·일정·목록·이미지를 `config/site.ts`와 `content`에 넣는다

새 요구가 오면 "어느 레벨인가"를 먼저 말하고 반영 위치(기본/유형/현장)를 정한 뒤 작업한다.

## 5. 후보를 추가·갱신할 때
1. 현장 메인 페이지의 상단 메뉴·하위 메뉴·본문 섹션을 확인해 `docs/benchmark.md` 매트릭스에 열을 추가한다.
2. 항목별 곳 수를 다시 센다. 기준을 넘거나 내려가는 항목의 레벨 변경을 기록한다.
3. 레벨이 바뀌면 `config/modules.js`(`level`, `note`)와 영향받는 유형을 수정한다.
4. 직접 열어 확인하지 못한 것은 "미확인"으로 표시한다. 추측으로 채우지 않는다.
5. 결론에는 항상 후보의 한계(브랜드 편중)를 함께 적는다.

## 6. 아직 비어 있는 것
- 신청 폼 입력 항목 10곳 (각 사이트의 관심고객등록/방문예약 페이지를 직접 열어 확인)
- 모바일 메뉴 구성
- 색상·타이포 비교 (디자인 시스템 기준이 필요할 때)
